# Mail → Telegram бот

Всё управление — кнопками, без команд (кроме самого первого `/start`, который Telegram требует для начала диалога). После `/start` появляется:
- постоянная кнопка **☰ Меню** внизу экрана — открывает главное меню из любого места;
- главное меню с кнопками **➕ Добавить почту**, **📋 Ящики**, **🔔 Категории писем**, **👥 Участники**, **❓ Помощь**.

Можно привязать сколько угодно ящиков (хоть 40) на один чат. В разделе «📋 Ящики» у каждого ящика своя кнопка 🗑 для отвязки (с подтверждением).

## Участники и доступ

Ящики общие: их видят и могут добавлять/отвязывать все участники, а уведомления получает каждый (настройки категорий у каждого свои).

Сейчас регистрация **открыта**: любой, кто напишет боту `/start`, становится участником (остальные получают сообщение о новом участнике). В разделе «👥 Участники» любой участник может:
- посмотреть список участников;
- закрыть/открыть регистрацию (кнопка 🔓/🔒) — пока она закрыта, новые люди не зайдут;
- удалить участника (🗑) или выйти сам (🚪). Последний участник выйти не может.

Совет: когда все нужные люди зашли — закрой регистрацию, иначе любой, кто найдёт бота, получит доступ ко всей почте.

## Категории писем

Бот сам определяет тип письма (сейчас: заявка на бронирование / объявление одобрено / объявление отклонено на Monteurzimmer.de, и SMS-коды вроде WhatsApp Business Code) и показывает его в уведомлении. В разделе «🔔 Категории писем» для каждого типа отдельные кнопки-переключатели:
- 🔔 Уведомлять — включить/выключить уведомления по этому типу писем вообще.
- 📄 Текст письма — присылать полный текст письма или только заголовок (от кого/тема/дата).

Письма, которые не попали ни в одну категорию, идут в «✉️ Остальные письма» (по умолчанию включены, с полным текстом — старое поведение не меняется). Настройки общие на чат и применяются ко всем привязанным ящикам сразу.

Чтобы научить бота новому типу писем — добавь правило в `CATEGORIES`/`classify()` в `bot.py` (матчинг по теме/телу письма).

## Outlook / Hotmail: вход через Microsoft

Microsoft не пускает личные ящики Outlook/Hotmail/Live по паролю, поэтому бот входит так же, как Thunderbird: показывает код и ссылку, пользователь сам входит на странице Microsoft и нажимает «Разрешить». Пароль боту не нужен.

Один раз нужно создать «приложение» Microsoft (бесплатно) и дать боту его Client ID:

1. Открой <https://entra.microsoft.com> (или portal.azure.com) и войди любой личной учёткой Microsoft.
2. **App registrations → New registration**. Имя любое (например, MailBot). В «Supported account types» выбери вариант с **personal Microsoft accounts** (лучше «Accounts in any organizational directory and personal Microsoft accounts»). Redirect URI не нужен. Нажми **Register**.
3. Слева **Authentication** → найди переключатель **Allow public client flows** → **Yes** → **Save**.
4. На странице **Overview** скопируй **Application (client) ID**.
5. Запусти установку с этим ID (на сервере от root):

```
curl -fsSL https://raw.githubusercontent.com/veritesClaude/hunay/ccr-5d79bc22-6d67we/mailbot/docker-install.sh | MS_CLIENT_ID=ВАШ_CLIENT_ID bash -s -- ТОКЕН_БОТА
```

Client ID запоминается на сервере (`/opt/mailbot-data/ms_client_id`), при обновлении его указывать повторно не нужно. После этого при добавлении адреса `@outlook.com/@hotmail.com/@live.com/…` бот сам покажет код и ссылку для входа.

## Установка в Docker, одной командой (на сервере, от root)

```
curl -fsSL https://raw.githubusercontent.com/veritesClaude/hunay/ccr-5d79bc22-6d67we/mailbot/docker-install.sh | bash -s -- ТОКЕН_БОТА ТВОЙ_TELEGRAM_ID
```

Сам поставит Docker (если его нет), склонирует код, соберёт образ и запустит контейнер `mailbot` с `--restart unless-stopped`. Данные (SQLite) лежат в `/opt/mailbot-data` на хосте, переживают пересборку и перезапуск.

Токен берёшь у `@BotFather`. Второй аргумент (Telegram ID, у `@userinfobot`) необязателен: указанные ID сразу добавляются в участники. Остальные заходят сами через `/start`, пока регистрация открыта.

Логи: `docker logs -f mailbot`
Остановить: `docker stop mailbot`
Обновить: перезапустить ту же команду. Ключ шифрования и данные хранятся в `/opt/mailbot-data` и сохраняются.

## Установка без Docker (systemd)

```
unzip mailbot.zip -d mailbot && cd mailbot && bash install.sh ТОКЕН_БОТА ТВОЙ_ID
```

Логи: `journalctl -u mailbot -f`
